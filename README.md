# 영어 단어 놀이 🍓

NGSL-Spoken(721) · New Dolch List(874) · NGSL-Graded Reader(5,000) 단어 5,079개를 테스트하는 웹앱입니다. (단어 목록 출처: newgeneralservicelist.com, CC BY-SA)

- 🐰 영어 → 뜻 (4지선다)
- 🐻 뜻 → 영어 (직접 쓰기 / 4지선다)
- 🐱 문장 빈칸 채우기 (단어당 예문 3개 중 랜덤, 직접 쓰기 / 4지선다)
- 💬 문장 모드: 문장 조립 연습(Be동사·일반동사·조동사), 실전 대화 표현, 영어일기 문장 — 뜻 고르기 / 블록 조립 / 빈칸
- ✏️ 영어일기 단어(기분·경험·맛·장소·동사·연결어)
- 📖 단어장 보기: 단어별 맞은/틀린 횟수, 예문·발음, 내 예문 추가
- 단어장·단계·알파벳 범위 선택, 오답노트(브라우저 저장), 틀린 것만 다시 풀기, 발음 듣기
