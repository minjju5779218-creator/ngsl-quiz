# 영어 단어 놀이 721 🍓

NGSL-Spoken 1.2 단어 721개를 테스트하는 웹앱입니다.

- 🐰 영어 → 뜻 (4지선다)
- 🐻 뜻 → 영어 (직접 쓰기 / 4지선다)
- 🐱 문장 빈칸 채우기 (단어당 예문 3개 중 랜덤, 직접 쓰기 / 4지선다)
- 알파벳 범위 선택, 오답노트(브라우저 저장), 틀린 것만 다시 풀기, 발음 듣기
